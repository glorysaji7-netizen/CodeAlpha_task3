# CodeAlpha_task_Car_Price_Prediction
# Car Price Prediction Using Machine Learning

## Project Overview

This project focuses on predicting the selling price of used cars using machine learning.

The main aim is to understand how different factors, such as the car's manufacturing year, present price, kilometres driven, fuel type, and transmission, can affect its selling price.

As part of my CodeAlpha Data Science Internship, I worked on this project using Python and machine learning techniques.

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

The dataset contains information about used cars, including:

- Car manufacturing year
- Present price
- Kilometres driven
- Fuel type
- Seller type
- Transmission type
- Previous owners
- Selling price

## Project Steps

1. Loaded and explored the car dataset.
2. Checked for missing values and duplicate records.
3. Cleaned and prepared the data for analysis.
4. Explored relationships between car features and selling prices.
5. Split the dataset into training and testing sets.
6. Built a Linear Regression model.
7. Built a Random Forest Regression model.
8. Compared the performance of both models.
9. Used the trained model to predict car selling prices.

## Machine Learning Models

Two machine learning algorithms were used:

- **Linear Regression:** Used to identify relationships between car features and selling prices.
- **Random Forest Regression:** Used to improve prediction performance by combining multiple decision trees.

## Model Evaluation

The models were evaluated using three performance metrics:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

The Random Forest model achieved better performance than Linear Regression on the test dataset.

## Conclusion

Through this project, I gained practical experience in data cleaning, exploratory data analysis, data visualisation, and machine learning.

I learned how to prepare data, train different regression models, compare their performance, and make predictions using real-world car information.

This project helped me understand how machine learning can be used to solve practical problems in the automobile industry.
